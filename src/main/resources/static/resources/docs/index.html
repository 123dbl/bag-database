Bag Database API Documentation

This page is bundled with the application so the Navigation menu always has a working API documentation target. Full Spring REST Docs output may replace this file in builds that run the documentation generation phase.

The public documentation site is available at https://swri-robotics.github.io/bag-database/rest-api/ .

Authentication

If LDAP or admin authentication is enabled, establish a session before calling API endpoints. POST requests must include a valid CSRF token. 

URL=http://localhost:8081
CSRF=$(curl -s -L -c cookies.txt "$URL/" \
    | sed -rn 's/^.*(value=|csrfToken = )"([-a-zA-Z0-9_-]*)".*$/\2/p')

curl -s -L -b cookies.txt -c cookies.txt \
    -F "username=admin" \
    -F "password=change-me" \
    -F "_csrf=$CSRF" \
    "$URL/ldap_login"

Bag Endpoints

Endpoint Method Purpose
/bags/search GET Search bags by text, filters, pagination, and sort order.
/bags/get GET Fetch one bag by database id.
/bags/download GET Download a bag file, including support for HTTP byte ranges.
/bags/upload POST Upload a bag file to a configured storage backend.
/bags/update POST Update mutable bag metadata such as location, vehicle, tags, and description.
/bags/getTagsForBag GET Return tags associated with a bag.
/bags/setTag, /bags/setTagForBags, /bags/removeTags POST Add or remove bag tags.

Example Search

curl -s -b cookies.txt \
    "$URL/bags/search?text=&page=1&start=0&limit=100&sort=filename&dir=ASC"

Script Endpoints

Endpoint Method Purpose
/scripts/list GET List configured scripts.
/scripts/save POST Create or update a script definition.
/scripts/run POST Run a script on one or more bag ids.
/scripts/list_results GET List script run results.
/scripts/get_result_by_uuid GET Fetch one script run result by UUID.
